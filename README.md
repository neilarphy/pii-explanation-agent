# pii-explanation-agent

## Структура

```
backend/
  api/          — эндпоинты FastAPI                                        (общее)
  schemas/      — общий формат: сессия, сработка, вердикт, сводка          (все)
  detectors/    — regex, NER, пороги, запись лога                          (Детекторы и модели)
  agent/        — промпты, инструменты, вердикт, сводка, рекомендации      (Агент)
  configs/      — паттерны, пороги, белый список                           (Детекторы и модели)
evaluation/     — метрики, простые правила, калибровка                     (Данные и оценка)
data/           — raw/ не в git, наши примеры и разметка                   (Данные и оценка)
serving/        — локальная LLM                                            (Детекторы и модели)
frontend/       — интерфейс под HiveTrace                                  (фронтенд)
scripts/        — скрипты скачивания данных и запуска оценки               (общее)
docs/           — примеры JSON, слайды, статья                             (все)
tests/          — тесты, запускаются в CI
```

Код запускается из корня репозитория: `uv run python -m backend.agent.<модуль>`.

## Разработка

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/).

```bash
uv sync                          # окружение и зависимости
uv run pre-commit install        # хуки перед каждым коммитом
uv run pre-commit run --all-files  # прогнать хуки вручную
uv run pytest                    # тесты
```

Что проверяется перед коммитом и в CI на каждом PR:

- `ruff check` и `ruff format` — стиль и типовые ошибки в коде и ноутбуках;
- валидность YAML, TOML и JSON, пробелы в концах строк, переводы строк LF;
- файлы больше 1 МБ — датасеты не коммитим, а скачиваем скриптом;
- `gitleaks` — ключи API и токены не должны попасть в репозиторий, держим их в `.env`.

Зависимость добавляется через `uv add <пакет>` (или `uv add --dev <пакет>` для инструментов), `uv.lock` коммитим вместе с `pyproject.toml`.
