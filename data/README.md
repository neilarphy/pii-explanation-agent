# Данные

- `raw/` — скачанные наборы и локальные журналы проверки. Каталог исключён из Git.
- `scenarios/` — небольшие JSONL со сложными диалогами и исправления эталонных спанов. Версия v1 и её исправления сохранены для воспроизведения прошлых прогонов.
- `reports/redmadrobot-manifest.json` — закреплённая ревизия, SHA256 и фактические счётчики redmadrobot.

Команды загрузки и описание источников приведены в [docs/datasets.md](../docs/datasets.md).

Новые сценарии генерируются через `uv run python -m scripts.generate_scenarios`.
`--split train|calibration|test` ограничивает генерацию выбранной выборкой.
По умолчанию пишется `scenarios-v2.jsonl`, а с `--split` имя дополняется названием выборки.
SHA256 идентификатора родительской группы назначает ей выборку с целевыми долями
60/20/20. Варианты с одним `group_id` наследуют выборку родителя. Разбиение не выявляет
семантические дубли с разными идентификаторами групп. У v2 идентификаторы сессий
начинаются с `sc-v2-`. Группа и выборка хранятся в
`session.meta`. Формат JSONL совместим с `scripts.run_detector --scenarios`.
Seed фиксирует значения заглушек. Чтобы воспроизвести диалоги, используйте сохранённый JSONL.
