# Локальная разметка Issue #14

Запустите команды из корня репозитория в PowerShell. Нужен Python 3.12 или новее с Tkinter. Первая команда создаёт рабочую копию только при её отсутствии.

```powershell
$source = '.\data\labeling\judge-kappa-v1\sheet.csv'
$working = '.\data\labeling\judge-kappa-v1\sheet-taisia.csv'
if (-not (Test-Path -LiteralPath $working -PathType Leaf)) {
    Copy-Item -LiteralPath $source -Destination $working
}
python -B .\scripts\label_judge_kappa.py
```

Пользуйтесь критериями из [инструкции](taisia-1-judge-kappa.md). Интерфейс открывает первую незаполненную строку. Для каждой оценки `0` укажите отдельную причину. Пустой рекомендации соответствует `n/a`. Если всю строку невозможно оценить, выберите «Не могу оценить строку».

Кнопка «Подтвердить и сохранить» записывает строку в рабочий CSV и открывает следующую. При повторном запуске работа продолжается с первой незаполненной строки. В сохранённой строке можно исправить техническую опечатку в комментарии по её ID.

После заполнения нажмите «Проверить таблицу» или выполните:

```powershell
python -B .\scripts\validate_judge_kappa_sheet.py
```

Для проверки свежей пустой копии добавьте `--blank`. Рабочий CSV содержит независимую ручную разметку. Перед её сдачей сохраняйте её отдельно от предварительного эксперимента Codex и избегайте сверки с его оценками.
