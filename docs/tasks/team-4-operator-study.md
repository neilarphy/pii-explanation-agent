# Таисия и Михаил, задача 4: помогает ли объяснение агента человеку

**Зачем.** Продукт — объяснение для оператора, который решает, маскировать ли фрагмент. Мы меряли
вердикты агента, но не меряли главное: **решает ли человек с объяснением точнее и быстрее, чем по одному
решению детектора, и не идет ли он слепо за агентом, когда тот ошибается**. В исследованиях люди
пропускают 46% ошибок уверенного ИИ против 17% без него — проверим, как у нас.

**Сроки:** участники — до 27.11, итог — до 28.11.

## Как устроено

Страница [data/labeling/operator-study-v1/study.html](../../data/labeling/operator-study-v1/study.html)
открывается в браузере без интернета и сервера. На ней 24 находки из диалогов в двух частях по 12:
- в одной части участник видит диалог, фрагмент и решение детектора;
- в другой — еще и ответ агента: «маскировать / не маскировать», объяснение и цитаты.

В каждой части 3 ответа агента неверные (участник об этом знает только в общих словах: «агент иногда
ошибается»). Вариант 1: первая часть без агента, вторая с агентом; вариант 2 — наоборот. Так каждая
находка решается в обоих условиях разными людьми, а усталость к концу не перекашивает итог.

Участник выбирает «маскировать / не маскировать / не уверен» и уверенность 1–5; время на каждую находку
страница пишет сама. В конце скачивается `results-<имя>-v<вариант>.csv`.

## Кто что делает

**Михаил:**
1. Проходит опыт сам (вариант 1), ~20–25 минут, за один присест, без перерывов внутри части.
2. Находит еще 3 участников не из нашей команды (одногруппники, знакомые), чтобы всего было 4+,
   четное число.

**Таисия** — организатор:
1. Раздает варианты по очереди: 1, 2, 1, 2… (поровну).
2. Отправляет участнику только `study.html` и вводный текст ниже — **не** `key.json` и не ссылку на репо.
3. Собирает `results-*.csv` в `data/labeling/operator-study-v1/` и считает итог:

        uv run python -m scripts.study score --dir data/labeling/operator-study-v1 \
            --out docs/reports/iter9/operator-study.md

4. Дописывает в отчет 3–5 наблюдений из комментариев участников (что мешало, чему не поверили).

**Не участвуют:** Анатолий (автор агента) и Таисия (видела ключ). Кто размечал задачу 1 — тоже нет:
часть диалогов там совпадает.

## Вводный текст для участника

> Это опыт для учебного проекта, ~20 минут. Открой файл `study.html` в браузере, введи имя и вариант
> (вариант: N). Решай в своем темпе, назад не возвращайся, ответы вне страницы не ищи. В конце
> скачай файл с ответами и пришли мне.

## Что получится

Таблица по двум условиям:
- **верно** — доля решений, совпавших с эталоном;
- **не уверен** — доля таких ответов;
- **медиана секунд на находку**;
- **ошибся там, где агент неверен** — те же 6 находок в обоих условиях: если с объяснением ошибок
  больше, чем без него, люди идут за агентом (переоценка ИИ);
- **ошибся там, где агент верен** — помогает ли верное объяснение по сравнению с одним детектором.

Участников мало (4–6), поэтому это пилот: в отчете — абсолютные числа, не только проценты. Неверные
ответы взяты у маленьких моделей (у основной на наших сценариях ошибок почти нет) — это тоже пишем.
