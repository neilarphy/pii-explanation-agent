# Задача для Claude Code: поправить профиль детектора

По 65 сессиям агент нашёл 18 повторяющихся проблем детектора (105 находок) и 9 разовых. Проблема — адресат правки (правило профиля или модель), вид ошибки и тип данных.

## 1. hivetrace/gliner-guard-omni: ложные срабатывания ADDRESS (17)

- Виды правки у агента: pattern — 9, retrain — 8
- Правка (pattern → `hivetrace/gliner-guard-omni`): Исключать из ADDRESS короткие формулировки-запросы или названия типа адреса без значения, например «адрес установки», «адрес», «укажите адрес», «адрес как в заявке»
- Почему: Модель приняла запрос адреса как значение адреса; score 0.54 выше порога, но фрагмент не содержит персональный адрес.
- Другая формулировка агента: Добавить в обучение примеры фраз-подтверждений, например «адрес верный», «адрес корректный», как не-адрес.
- Другая формулировка агента: Добавить негативные примеры для метки ADDRESS: «указанную почту», «на почту», «на указанный адрес», «на номер», если рядом нет фактического значения адреса/email/телефона.
- Примеры: «адрес верный» (сессия sc-bot_echo-5); «указанную почту» (сессия sc-service_contacts-5); «адрес установки» (сессия sc-injection-3)
